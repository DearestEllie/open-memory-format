# Examples

Complete, valid Open Memory Format 1.1 documents. Both validate against
[`../schema/omf-1.1.schema.json`](../schema/omf-1.1.schema.json).

- [`nora-hart.omf.json`](nora-hart.omf.json) — a small fictional archive
  (Nora Hart, a town librarian) named with the `.omf.json` compound extension:
  chapters, stories, a recipe, a timeline event, a letter, a photo with a
  `mediaFiles` entry.
- [`export.example.json`](export.example.json) — the original example archive
  (Eleanor "Ellie" Marsh), refreshed to 1.1, named as the `export.json` found
  inside a `.omf.zip`.

Everyone in these files is fictional.
